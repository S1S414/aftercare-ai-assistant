# 免费在线演示部署

本模式用于公开体验模拟售后流程，不处理真实订单。未配置或调用真实模型；整理采用规则分类和原文保留，问答采用政策摘录。页面明确标注模拟结果。

## Render 免费部署

1. 登录 Render，创建 Blueprint，连接本仓库，读取根目录 render.yaml。
2. 确认 Web Service 的 plan 为 free。无需持久磁盘、付费数据库或模型密钥。
3. 部署完成后打开服务的 HTTPS 地址。健康检查路径为 /health。
4. 点击“以顾客身份体验”，选择 DEMO-002，在售后助手保存草稿、核对建单。
5. 点击“切换客服处理本次工单”，领取工单，填写模拟结果并关闭。
6. 切回顾客查看结果，再核对客服统计。

配置已包含：生产会话 Cookie、随机服务密钥、公开演示开关、单 worker Gunicorn。不要增加 worker 数；本版本的临时数据清理锁在单进程内生效。

## 数据边界

- 每个浏览器会话分配独立 SQLite 数据库，角色切换保留该会话的数据。
- 退出登录或浏览器会话失效后需重新体验，不承诺恢复旧数据。
- 数据库超过24小时未修改后，在下一次访问服务时清理；空闲无访问时不运行定时清理。
- Render 免费服务休眠、重启或重新部署可能清空全部临时数据。
- 最多100个临时空间，每个空间达到2 MiB后停止新增操作；这只是小规模演示容量限制。
- 不上传本地数据库、备份或个人材料，不开放本机存储维护工具。
- 演示模式不产生模型调用记录或费用；真实模型流程可在本地配置自己的密钥体验。

## 验证

运行 `python -m unittest discover -s tests`。新增测试覆盖跨访客隔离、跨角色建单到关闭、CSRF、过期清理、无真实模型请求及本地模式兼容。

本模式尚不代表正式生产服务；上线后还需实际核对公网可达性及移动端体验。
