# 本地存储维护

本机维护工具只用于本地文件管理，不应作为公网后台开放。不需要客服登录，不发起模型请求。

## 顾客删除草稿

售后助手 → 我的售后任务：按订单和状态查询，打开或删除本人未建单草稿。页面另将已取消超过7天、待确认且7天未修改的草稿归组。选择后核对清单并确认；删除不可撤销，正式工单不在此删除。

## 维护调用记录与备份

1. 在网站运行窗口按Ctrl+C停止服务，关闭其他数据库工具。
2. 在项目目录双击open-storage-manager.cmd。它优先使用.venv，其次使用.venv-acceptance；也可运行 `.\.venv\Scripts\python.exe storage_manager.py`。需Python支持Tkinter。
3. 选择“已结束超过7天的调用记录”或“项目备份文件”。
4. 选择待删除记录，点击“清理所选并整理空间”，核对清单；确认后永久删除，可在确认前取消。
5. 查看删除数量及整理前后字节数，再重新启动网站。

维护工具不保存密钥，不自动调用模型。处理中、时间异常或处于保留窗口的调用不纳入清理。

## 结果与限制

- 删除草稿会移除当前数据库内对应草稿与操作记录，不连带删除调用记录或独立备份。
- 数据库删除后，空间可能供内部复用。整理后文件也可能不缩小，工具必须按实际报告；不能用删除条数代替释放字节数。
- 备份只处理instance/restore-checks内规定的backup.sqlite3、restored.sqlite3及instance/backups/*.sqlite3。主数据库与其他外部文件不作为备份删除。
- 合计大小包括数据库及附属文件和工具管理的备份，不是整块硬盘占用。
- 整理失败不会撤销已完成的删除；备份删除遇到错误可能部分完成。保留错误结果核查，勿盲目重试。
- 要求服务端口空闲和数据库可排他访问；WAL模式拒绝整理。空间整理可能需要额外临时磁盘空间。
- 这是正常数据库删除和文件删除，不承诺专业防恢复擦除；自动备份轮换尚未实现。
